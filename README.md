Project 100 Belgians (100 Unequal People for the global name if expended to other countries)

**INTRO**

A website that illustrates inequality by using 100 fictional Belgians as an example.
It would generate 100 Belgian profiles based on real income + wealth data, then extrapolate their life situations using ChatGPT and real-world data when available.
 Ideas for comparison points:
- Holidays (once a year, twice a year, where?)
- Buying a smartphone
- Going to restaurants
- How easy it is to go to a Taylor Swift concert (impossible vs “on a whim”)
- Homeownership (owner of 1 home, 2 homes, or more)


Job types: politician, self-employed, secondary-school teacher, Walloon Region civil servant, etc.


For people who want to, they can fill in a questionnaire and see which profile is closest to them. A chart shows where they fall in the hierarchy. The goal is to highlight the bias where people think they’re “middle class” when they are actually rich—and vice versa.
Two axes/lines: Income and Assets. Everyone sits somewhere on that scale, and you can sort profiles by it.
Tags to filter the “bucket” of Belgians:
Language
- Retired vs working
- Ancestry, etc.

# Current state

- **Data**: `src/data/profiles.js` holds 100 fictional adults, one per income
  percentile (0.5 … 99.5), so the whole distribution is represented — including
  the top 1%. It is generated by `node scripts/generate-profiles.mjs`
  (deterministic, seeded), whose anchor values are interpolated from Statbel
  salary/fiscal statistics and the NBB/ECB Household Finance and Consumption
  Survey; sources and method are documented in the script. Wealth rank is
  correlated with income and age, jobs/regions/languages are drawn plausibly
  per income level.
- **Interactive "wealth parade"** (`src/components/WealthParade.vue`): all 100
  people as bars on a deliberately linear scale, toggle between wealth and
  income, hover/arrow-key tooltips, click to pin a person and see their life
  situation (holidays, eating out, phone, concerts, housing — derived in
  `src/data/lifestyle.js`). A "Where would you land?" input places the visitor
  in the parade.
- **Income by source**: the income view stacks each bar into "from work &
  pensions" vs "from wealth" (rent, dividends, interest), modelled in
  `src/data/incomeSources.js` (~3.2% net return on non-primary-home wealth,
  capped at 85% of income). At the top of the parade, income stops coming from
  work — the top 10 draw ~60% of income from wealth vs ~3% for the bottom 50.
  Deep link: `/profiles?view=income`.
- **Perception gap**: the landing page and profiles view explain why almost
  everyone believes they are middle class (social-circle calibration; Hauser &
  Norton 2017, Bublitz 2020).

**TECH**

## Deploying to GitHub Pages

This repository is configured to deploy automatically to GitHub Pages with GitHub Actions.

1. Push to the `main` branch.
2. In GitHub, go to **Settings → Pages**.
3. Set **Source** to **GitHub Actions**.
4. Wait for the **Deploy to GitHub Pages** workflow to finish.

The production base path is automatically set to `/100-unequal-people/` when built inside GitHub Actions, so assets resolve correctly on Pages.
